# 회사 업무 위키 — 공개 열람 / 관리자 로그인

Python 표준 라이브러리와 SQLite만으로 작동하는 1차 서버형 MVP입니다. **데모 수준의 초기 운영 코드**이며 공개 인터넷 배포 전 아래 보안 점검이 필요합니다.

## 실행

Python 3.10 이상 설치 후 터미널에서:

**Linux / macOS**
```bash
export WIKI_ADMIN_PASSWORD='여기에_충분히_긴_관리자_비밀번호_입력'
python3 app.py
```
**Windows PowerShell**
```powershell
$env:WIKI_ADMIN_PASSWORD='여기에_충분히_긴_관리자_비밀번호_입력'
python app.py
```

브라우저에서 `http://127.0.0.1:8080` 접속. 우측 상단 관리자 로그인: 아이디 `admin`, 위에서 설정한 비밀번호. 데이터는 `wiki.sqlite3`에 보관됩니다.

초기 관리자 계정은 데이터베이스 생성 시에만 만들어집니다. 이후 환경변수의 비밀번호만 바꿔도 기존 계정의 비밀번호는 변경되지 않습니다. 계정 변경 기능은 추후 추가가 필요합니다.

## 기능
- 로그인 없이 게시된 문서 읽기 및 제목·본문 검색
- 관리자 로그인, 카테고리 생성·삭제, 문서 작성·수정·영구 삭제
- 임시저장/공개 게시, 수정 이력 및 복원
- SQLite 영구 저장, CSRF 토큰, 비밀번호 scrypt 해시, 로그인 시도 제한, 세션 쿠키
- 모바일 반응형

## 한계 및 운영 전 필수 작업
- **현재 외부 인터넷에 바로 공개하지 마세요.** 로컬에서 기능 검증을 위한 첫 서버형 구현입니다.
- 반드시 Caddy 또는 Nginx 등의 HTTPS 역방향 프록시 뒤에 배치하고 `WIKI_SECURE_COOKIE=1` 설정. 웹 서버 자체는 `127.0.0.1`에서만 실행합니다.
- 실제 외부 공개 전 전문적인 보안 검토, 접근 로그, 서버 방화벽, 자동 백업 및 복구 테스트 필요.
- 공개 문서는 전 세계 누구나 볼 수 있습니다. 개인정보·기밀·암호는 게시하지 마세요.
- 관리자 비밀번호 재설정, 다중 관리자, 첨부파일 업로드, WYSIWYG 편집기, 고급 검색, 삭제 휴지통 등은 아직 구현되지 않았습니다.
- 관리자 로그인 시도 제한은 메모리 기반이므로 서버 재시작 및 다중 인스턴스 환경에서는 초기화됩니다. 운영 환경에서는 프록시 단의 추가 제한이 필요합니다.
- DB 백업은 실행 중 단순 파일 복사보다 SQLite 온라인 백업 API 또는 `sqlite3 .backup`을 사용하세요.
- 문서 내용은 안전하게 일반 텍스트로 출력합니다. HTML/Markdown 서식 편집은 지원하지 않습니다.

## 구성
`app.py` 실행 서버 / `wiki.sqlite3` 최초 실행 후 자동 생성 / `schema.sql` 참고용 스키마.
